# Generated model documentation

The RST files in this directory are generated by
[`doc/source/gen_docs.py`](../../gen_docs.py). Do not edit them manually.

Update the corresponding model registry or `model_spec.json` and, when the
rendered structure needs to change, the Jinja template under `doc/templates/`.
Then regenerate the documentation from `doc/source`:

```bash
python gen_docs.py
```
